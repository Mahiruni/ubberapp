# Provisional NexRide mark

`nexride-folded-n.svg` is an original folded emerald N concept created for the rider splash. It is provisional and is not represented as the approved final logo. The repository currently has app icons, but no supplied standalone NexRide symbol matching the reference. Existing app icons and in-app branding are unchanged.

Supply the approved transparent logo in `public/brand/` and update `RiderSplash` to use it. Keep the concept in this clearly separate `provisional/` directory until the final asset is approved.
